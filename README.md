# Prism Theme for Artic Horizon 2

Prism theme styled to match **[Artic Horizon 2](https://github.com/jurialmunkey/skin.arctic.horizon)**. Custom-styled Prism dialogs aligned with AH2 visuals.

Part of the [Prism](https://github.com/Goldenfreddy0703/Prism) ecosystem. See the [Themes wiki](https://github.com/Goldenfreddy0703/Prism/wiki/Themes) for developer documentation.

## Skinned Windows

This theme includes custom layouts for:

- SmartPlay / Playing Next (`playing_next.xml`)
- Scraping (`get_sources.xml`)
- Source Select (`source_select.xml`)
- Resolving (`resolver.xml`)
- Provider Manager (`provider_packages.xml`)
- Provider Package Config (`configure_provider_package.xml`)
- Still Watching (`still_watching.xml`)
- Skip Segment (`skip_segment.xml`)
- Skip Outro (`skip_outro.xml`)
- Persistent Background (`persistent_background.xml`)

> This theme does **not** include `custom_providers.xml` — that window uses the Prism Default skin.

## Requirements

- **Prism** 2.x or greater
- **Artic Horizon 2** (latest repository version)

> This theme is a modified version of PrismTheme-PrismMod-Full. Use at your own risk with other Kodi skins.

The text highlight color is controlled by Prism's **Select Text Highlight Color** setting (Prism Settings → Interface).

## Install

**Web Location:**

1. Go to **Prism → Tools → Theme Manager → Install Theme → Web Location**
2. Enter this URL:

```
https://github.com/Goldenfreddy0703/prism.theme.ah2/zipball/main/
```

**Browse:**

1. Download the zip from the URL above
2. Go to **Prism → Tools → Theme Manager → Install Theme → Browse**
3. Select the downloaded zip file

## Post-Install

1. Go to **Prism → Tools → Theme Manager**
2. Select this theme from the list
3. Confirm **Artic Horizon 2** is your active Kodi skin

To switch back, select **Prism Default** in Theme Manager.
